BiliBili ShadowReplay 可以边录制直播边剪辑投稿。选中想保留的时间段，编辑切片、填写投稿信息，整个流程可在几分钟内完成。直播结束后，也可以回放已缓存的录播，按同样的方式剪辑和投稿。

目前支持录制的直播平台：

- B 站
- 抖音
- 斗鱼
- TikTok
- Twitch
- 快手
- 虎牙
- YouTube
